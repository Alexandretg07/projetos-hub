## Atividades

### Aula 01 — Calculadora simples

Trabalha entrada de dados com `prompt`, conversão de valores com `Number`, variáveis, operadores aritméticos, operadores de comparação e identificação de tipos com `typeof`. Os resultados são apresentados no console do navegador.

### Aula 02 — Classificador de resultados

Utiliza funções para validar notas, calcular médias e classificar resultados. Também aplica estruturas condicionais (`if/else`), repetição (`for`, `while` e `do...while`) e apresenta o resumo dos alunos no console.

### Aula 03 — Classificador de alunos

Aplicação web com formulário para cadastrar alunos e três notas. Calcula a média, classifica a situação (Aprovado, Recuperação ou Reprovado), valida os campos, atualiza a lista na página e permite remover alunos ou limpar a lista. A interface utiliza HTML e CSS, enquanto a lógica e as interações são feitas em JavaScript com manipulação do DOM e eventos.

## Tecnologias e recursos

- HTML5
- CSS3
- JavaScript
- `prompt`, `confirm` e `console`
- Funções, variáveis, operadores e estruturas de controle
- DOM e eventos

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta `javascript`.
3. Entre na pasta da aula desejada.
4. Abra o arquivo HTML correspondente no navegador.
5. Nas aulas 01 e 02, responda às janelas de entrada e consulte os resultados em **F12 → Console**. Na aula 03, utilize diretamente o formulário exibido na página.

Não é necessário instalar dependências ou executar um servidor local.
